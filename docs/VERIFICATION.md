# MVP 驗證紀錄

## 視覺驗證

桌面版以 1440 × 1000 視窗檢查。頁面已正確呈現暖米白背景、深海軍藍策略卡、低對比金色幾何線條與具編輯感的標題層級。局前規劃同時顯示人數、菜系、時段、五局、三層、目標輸入及四筆相符知識卡；文字可讀、色彩對比足夠，且沒有可見的重疊或水平溢出。

先前在 390 × 844 手機尺寸的檢查中，主視覺、分段導覽、三項情境篩選、五局與三層按鈕、輸入欄位及相符知識卡均依單欄順序清楚排列，沒有文字重疊或水平溢出。

## 資料與登入流程

系統資料庫已匯入 54 筆正式課程資料：六大部分 32 筆、七大角色 7 筆及五局十五層 15 筆。局前篩選依人數、菜系、時段保留「不限」或相符條目。

飯局紀錄與個人化設定均由 `protectedProcedure` 保護，只有 Manus OAuth 的已登入使用者可存取。Vitest 以具備 `userId: 42` 的已登入 tRPC 呼叫端驗證：飯局紀錄儲存時會帶入該使用者 ID；個人化設定可寫入三項局前預設；同一使用者可讀取自己的設定與紀錄清單。前端「我的紀錄」頁面亦提供相應的局後筆記、儲存按鈕及常用人數／菜系／時段設定介面。

## 智慧建議流程

以「5–8 人／中式合菜／晚餐／破冰第 1 層」的情境實際呼叫服務，已取得受知識庫來源約束的執行摘要、四個話題建議、七大角色策略、風險提醒、明確的局後復盤摘要、復盤問題與來源條目。以含有局後筆記的請求驗證時，摘要會引用筆記中「目標對象主動追問」與「橋接人串起共同朋友」兩項觀察，並依來源提醒早期局避免會議式溝通。

模型輸出解析支援 JSON 程式碼區塊，並會將超過介面可讀範圍的陣列安全截取；缺少必要欄位的回覆則會被拒絕。
