# 預設驅動的情境引導規格

## 目的

此功能在使用者尚未準備好完整目標或人物背景時，先以局前規劃中的**目前選擇**建立一份可修正的情境草圖。它不推定他人的意圖、身份、決策權或文化偏好；每一項尚未確認的資訊都必須明確標為「假設」或轉為釐清問題。

## 可使用的預設

已登入使用者的已儲存預設只有飯局人數、菜系與時段。進入局前規劃後，系統會將這三項載入表單；情境引導以此三項加上使用者當下選定的局別、對話深度、目標與人物背景產生結果。未登入使用者則以目前表單選擇為準。

| 區塊 | 輸入 | 輸出規則 |
| --- | --- | --- |
| 已知條件 | 人數、菜系、時段、局別、層次、已填目標與人物背景 | 只重述使用者選擇，不另行推論。 |
| 情境假設 | 目前缺少但會影響策略的資訊 | 最多 3 項；必須使用「若／尚未確認」語句，不可寫成既定事實。 |
| 待釐清問題 | 目標、關係、決策、下一步與限制等缺口 | 最多 4 題；每題指出為何值得確認，並可將建議文字帶回目標或人物背景欄。 |
| 注意事項 | 對話推進、角色判讀、合規與跨文化互動的風險 | 最多 4 項；只引用相符的課程條目、研究補充與局別資料。 |
| 建議下一步 | 使用者完成一個最關鍵問題後應採取的動作 | 一句可執行動作；不承諾結果，不代替使用者判斷。 |

## 知識庫與回退規則

情境引導與現有智慧建議共用人數、菜系、時段篩選後的公開知識庫條目，並維持「課程條目優先、研究補充至多三筆」的來源組合。模型回覆一律以結構化 JSON 驗證，逾時或解析失敗時改用固定的知識庫備援內容。研究補充的來源名稱、網址與使用邊界必須隨結果回傳；一般課程條目只顯示於依據清單。

## 使用流程

使用者可在填寫完整目標之前按下「先釐清這一局」。結果會先顯示已知條件、假設、問題與注意事項。使用者可把個別問題的提示帶入「本次飯局目標」或「人物背景與關係線索」後，再產生既有的智慧建議。這使產出從單向建議改為先釐清、再推進的流程。
